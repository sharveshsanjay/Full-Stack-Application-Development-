## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/sharveshsanjay/Full-Stack-Application-Development-.git
```

### Navigate to the Project Directory

```bash
cd Full-Stack-Application-Development-
```

### Open a Task

Navigate to the folder of the required task:

```bash
cd "Task 1"
```

For example, to access the student registration task:

```bash
cd "Task 1/student-registration"
```

Follow the instructions provided inside each task or project folder to install the required dependencies and run the application.

For Node.js projects, install the dependencies using:

```bash
npm install
```

Start the application using:

```bash
npm start
```
